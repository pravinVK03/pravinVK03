### DeepScapes: Unified Project-Centric Workspace
*Product Designer · Team of four · Deployed on Vercel*

A web workspace in which each project is a single **Scape** holding notes, tasks, links, documents and media. Includes an embedded remote browser for in-project research, role-based collaboration (owner, editor, viewer) enforced on the server, and an audit history with a Resume card for continuity.

### Adaptive Digital Twin for Type 2 Diabetes
*Machine Learning course project · Python*

Patient health-state modelling and disease trajectory prediction. A patient-specific state is initialized from clinical records, updated by an explicit rule as new observations arrive, and used to predict a defined future outcome. Evaluated retrospectively against non-adaptive baselines with patient-level, leakage-resistant data splits.

### Ashroot: AI-Powered File Retrieval
*Design Patterns course project · Next.js / TypeScript*

Natural-language retrieval of uploaded documents and images through generated metadata. The architecture combines **Composite** (semantic metadata tree), **Strategy** (swappable retrieval algorithms) and **Chain of Responsibility** (query-processing stages) to keep each concern independently testable and extensible.
